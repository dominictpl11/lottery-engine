# 项目运行说明

## 🚀 快速启动

### 方式一：使用Maven（推荐）

如果已安装Maven，在项目根目录执行：

```bash
mvn spring-boot:run
```

### 方式二：使用IDE

1. **IntelliJ IDEA**
   - 打开项目
   - 找到 `src/main/java/com/seckiller/lottery/LotteryApplication.java`
   - 右键选择 "Run 'LotteryApplication.main()'"

2. **Eclipse**
   - 导入Maven项目
   - 找到 `LotteryApplication.java`
   - 右键选择 "Run As" -> "Java Application"

### 方式三：打包后运行

```bash
# 1. 打包项目
mvn clean package

# 2. 运行jar包
java -jar target/lottery-engine-1.0.0.jar
```

### 方式四：使用启动脚本

Windows系统可以直接双击 `start.bat` 文件。

## 📋 运行前检查清单

### 1. 环境要求

- ✅ JDK 1.8+
- ✅ Maven 3.6+（如果使用Maven命令）
- ✅ MySQL 8.0+
- ✅ Redis 6.0+
- ⚠️ RocketMQ 4.9+（可选，如果使用MQ功能）
- ⚠️ ZooKeeper 3.7+（可选，如果使用Dubbo）

### 2. 数据库准备

```sql
-- 1. 创建数据库
CREATE DATABASE IF NOT EXISTS lottery_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 2. 使用数据库
USE lottery_db;

-- 3. 执行表结构脚本（在MySQL客户端中执行）
SOURCE src/main/resources/db/schema.sql;

-- 4. 执行测试数据脚本
SOURCE src/main/resources/db/test-data.sql;
```

或者直接复制 `src/main/resources/db/schema.sql` 和 `test-data.sql` 的内容到MySQL客户端执行。

### 3. 服务启动

#### Redis
```bash
# Windows
redis-server

# Linux/Mac
redis-server /etc/redis/redis.conf
```

#### RocketMQ（可选）
```bash
# 启动NameServer
mqnamesrv

# 启动Broker
mqbroker -n localhost:9876
```

#### ZooKeeper（可选，如果使用Dubbo）
```bash
# Windows
zkServer.cmd

# Linux/Mac
zkServer.sh start
```

### 4. 配置文件检查

检查 `src/main/resources/application.yml` 中的配置：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/lottery_db?...
    username: root      # 修改为你的MySQL用户名
    password: root      # 修改为你的MySQL密码
  
  redis:
    host: localhost
    port: 6379
    password:           # 如果有密码，填写Redis密码
```

## ❌ 常见问题

### 1. Maven命令不可用

**问题**: `mvn: 无法识别为 cmdlet、函数、脚本文件或可运行程序`

**解决**:
- 安装Maven并配置环境变量
- 或使用IDE运行项目
- 或使用已编译的jar包运行

### 2. 数据库连接失败

**问题**: `Could not connect to database`

**解决**:
- 检查MySQL服务是否启动
- 检查数据库是否已创建
- 检查用户名密码是否正确
- 检查 `application.yml` 中的数据库配置

### 3. Redis连接失败

**问题**: `Unable to connect to Redis`

**解决**:
- 检查Redis服务是否启动
- 检查Redis配置是否正确
- 如果Redis有密码，在配置文件中填写密码

### 4. 端口被占用

**问题**: `Port 8080 is already in use`

**解决**:
- 修改 `application.yml` 中的端口号
- 或关闭占用8080端口的程序

### 5. RocketMQ连接失败（可选）

如果不需要MQ功能，可以暂时忽略RocketMQ连接错误。项目仍可运行，只是MQ相关功能不可用。

### 6. ZooKeeper连接失败（可选）

如果不需要Dubbo功能，可以暂时忽略ZooKeeper连接错误。项目仍可运行，只是Dubbo服务不可用。

---

## 📝 注意事项

1. **最小运行环境**: 项目至少需要MySQL和Redis才能正常运行
2. **RocketMQ和ZooKeeper**: 这两个服务是可选的，如果未启动，相关功能不可用，但不影响基本抽奖功能
3. **测试数据**: 确保已执行测试数据脚本，否则可能没有活动数据
4. **日志级别**: 默认日志级别为DEBUG，可以在 `application.yml` 中调整
