# 项目启动检查清单

## ✅ 启动前必须完成

### 1. 数据库准备

- [ ] MySQL服务已启动
- [ ] 创建数据库：`CREATE DATABASE lottery_db;`
- [ ] 执行 `schema.sql` 创建表
- [ ] 执行 `test-data.sql` 插入数据
- [ ] 验证数据：`SELECT COUNT(*) FROM activity;` 返回 2

### 2. Redis准备

- [ ] Redis服务已启动
- [ ] 测试连接：`redis-cli ping` 返回 PONG

### 3. 配置文件检查

- [ ] `application.yml` 中数据库用户名正确（默认：root）
- [ ] `application.yml` 中数据库密码正确（默认：root）
- [ ] `application.yml` 中Redis配置正确

### 4. 端口检查

- [ ] 8080端口未被占用

---

## 🚀 启动步骤

1. [ ] 停止现有Java进程：`Get-Process -Name java | Stop-Process -Force`
2. [ ] 启动项目：`.\mvnw.cmd spring-boot:run`
3. [ ] 等待启动（首次1-3分钟）
4. [ ] 检查8080端口：`Get-NetTCPConnection -LocalPort 8080`
5. [ ] 测试健康接口：访问 `http://localhost:8080/lottery/api/lottery/health`

---

## ✅ 启动成功标志

- [ ] 控制台显示：`Started LotteryApplication`
- [ ] 8080端口正在监听
- [ ] 健康检查返回：`OK`

---

## ❌ 如果启动失败

查看Maven控制台日志，查找错误信息：
- 数据库错误 → 检查数据库
- Redis错误 → 检查Redis
- 端口占用 → 关闭占用程序
- 编译错误 → 修复代码
