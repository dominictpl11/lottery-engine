# 快速启动指南

## ✅ 启动前检查清单

在启动项目前，请确保：

- [ ] **MySQL服务已启动**
- [ ] **数据库 `lottery_db` 已创建**
- [ ] **数据库表已创建**（执行了schema.sql）
- [ ] **测试数据已插入**（执行了test-data.sql）
- [ ] **Redis服务已启动**（`redis-cli ping` 返回PONG）
- [ ] **8080端口未被占用**

## 🚀 启动步骤

### 1. 停止现有进程（如果存在）

```powershell
Get-Process -Name java | Stop-Process -Force
```

### 2. 启动项目

```powershell
.\mvnw.cmd spring-boot:run
```

### 3. 等待启动（首次启动需要1-3分钟）

### 4. 检查启动状态

```powershell
# 检查8080端口
Get-NetTCPConnection -LocalPort 8080

# 测试健康接口
Invoke-WebRequest -Uri "http://localhost:8080/lottery/api/lottery/health" -UseBasicParsing
```

## 🔍 如果启动失败

### 检查数据库

```sql
-- 在MySQL客户端执行
SHOW DATABASES LIKE 'lottery_db';
USE lottery_db;
SHOW TABLES;
```

### 检查Redis

```bash
redis-cli ping
# 应该返回: PONG
```

### 查看启动日志

查看Maven控制台输出，查找错误信息。
