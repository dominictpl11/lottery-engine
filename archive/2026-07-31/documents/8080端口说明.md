# 8080端口说明

## 🎯 8080端口的作用

**8080端口** 是这个抽奖引擎项目的 **HTTP服务端口**，用于提供 **REST API接口**。

---

## 📋 详细说明

### 1. 端口配置

在 `application.yml` 中配置：
```yaml
server:
  port: 8080                    # HTTP服务端口
  servlet:
    context-path: /lottery       # 应用上下文路径
```

### 2. 完整的访问地址

- **基础URL**: `http://localhost:8080`
- **应用路径**: `/lottery`
- **完整基础URL**: `http://localhost:8080/lottery`

---

## 🔌 提供的服务

### 1. 健康检查接口

**用途**: 检查服务是否正常运行

**访问地址**: 
```
GET http://localhost:8080/lottery/api/lottery/health
```

**响应**: 
```
OK
```

**使用场景**:
- 监控系统检查服务状态
- 负载均衡器健康检查
- 运维人员快速验证服务是否启动

---

### 2. 抽奖接口

**用途**: 执行抽奖操作

**访问地址**: 
```
POST http://localhost:8080/lottery/api/lottery/draw
```

**请求示例**:
```json
{
  "uId": "user001",
  "activityId": 100001
}
```

**响应示例**:
```json
{
  "uId": "user001",
  "activityId": 100001,
  "awardInfo": {
    "awardId": "104",
    "awardType": 3,
    "awardName": "100元优惠券",
    "awardContent": "COUPON_100_2024"
  },
  "strategyId": 100001,
  "drawState": 1,
  "drawStateName": "已中奖"
}
```

**使用场景**:
- 前端页面调用抽奖功能
- 移动App调用抽奖API
- 第三方系统集成

## 🌐 端口的作用

### 1. HTTP服务监听

8080端口是Spring Boot内嵌的Tomcat服务器监听的端口，用于：
- 接收HTTP请求
- 处理REST API调用
- 返回JSON响应

### 2. 为什么选择8080？

- **8080** 是Java Web应用常用的端口（Tomcat默认端口）
- 避免与系统常用端口冲突（如80、443）
- 开发环境常用端口，易于记忆

### 3. 可以修改吗？

**可以！** 如果需要修改端口，在 `application.yml` 中修改：

```yaml
server:
  port: 9090  # 改为其他端口，如9090
```

修改后，访问地址变为：
```
http://localhost:9090/lottery/api/lottery/health
```

## ⚠️ 常见问题

### 问题1：端口被占用

**错误信息**: `Port 8080 is already in use`

**原因**: 其他程序正在使用8080端口

**解决方案**:
1. 关闭占用端口的程序
2. 或修改 `application.yml` 中的端口号

**查找占用端口的程序**:
```powershell
# Windows
netstat -ano | findstr :8080
# 找到PID后，查看进程
tasklist | findstr <PID>
```

### 问题2：无法访问

**可能原因**:
- 项目还未启动完成
- 防火墙阻止了8080端口
- 服务启动失败

**解决方案**:
1. 等待项目完全启动（检查日志）
2. 检查防火墙设置
3. 查看启动日志中的错误信息
