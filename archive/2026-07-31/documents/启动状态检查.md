# 项目启动状态

## 🚀 启动命令

已使用Maven Wrapper启动项目：
```bash
.\mvnw.cmd spring-boot:run
```

## ⏳ 启动过程

项目正在后台启动中，首次启动可能需要：
1. **下载Maven Wrapper**（如果还没有）
2. **下载项目依赖**（首次运行需要下载所有jar包）
3. **编译项目代码**
4. **启动Spring Boot应用**

预计时间：1-3分钟（取决于网络速度和依赖下载）

## ✅ 验证启动成功

### 方法1：检查端口
```bash
netstat -ano | findstr :8080
```
如果看到8080端口被占用，说明项目已启动。

### 方法2：健康检查
打开浏览器访问：
```
http://localhost:8080/lottery/api/lottery/health
```
应该返回：`OK`

### 方法3：查看日志
项目启动日志会显示在控制台，成功启动会看到：
```
Started LotteryApplication in X.XXX seconds
```

## ⚠️ 注意事项

1. **首次启动**：需要下载依赖，可能需要较长时间
2. **数据库连接**：确保MySQL已启动并创建了`lottery_db`数据库
3. **Redis连接**：确保Redis服务已启动
4. **端口占用**：如果8080端口被占用，需要修改`application.yml`中的端口

## 🔍 如果启动失败

常见问题：
- **数据库连接失败**：检查MySQL服务和数据库配置
- **Redis连接失败**：检查Redis服务
- **端口被占用**：修改端口或关闭占用端口的程序
- **依赖下载失败**：检查网络连接或配置Maven镜像

## 📝 停止项目

如果需要停止项目，按 `Ctrl+C` 或关闭终端窗口。
