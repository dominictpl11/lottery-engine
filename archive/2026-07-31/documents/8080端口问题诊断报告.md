## 🔍 可能的原因

### 1. 项目正在启动中（最可能）

**现象**: Java进程已启动，但8080端口尚未监听

**原因**:
- 首次启动需要下载Maven依赖（可能需要1-3分钟）
- 项目正在编译中
- Spring Boot正在初始化

**解决方案**: 
- 继续等待（建议等待2-3分钟）
- 查看控制台日志了解启动进度

---

### 2. 数据库连接失败

**现象**: 项目启动过程中遇到数据库连接错误

**检查方法**:
```sql
-- 检查MySQL服务是否运行
-- 检查数据库是否存在
SHOW DATABASES LIKE 'lottery_db';

-- 检查数据库是否已创建表
USE lottery_db;
SHOW TABLES;
```

**解决方案**:
1. 确保MySQL服务已启动
2. 创建数据库：`CREATE DATABASE lottery_db;`
3. 执行 `schema.sql` 和 `test-data.sql`
4. 检查 `application.yml` 中的数据库配置

---

### 3. Redis连接失败

**现象**: 项目启动过程中遇到Redis连接错误

**检查方法**:
```bash
redis-cli ping
# 应该返回: PONG
```

**解决方案**:
1. 确保Redis服务已启动
2. 检查 `application.yml` 中的Redis配置
3. 如果有密码，确保配置正确

---

### 4. 端口配置问题

**检查配置**:
```yaml
# src/main/resources/application.yml
server:
  port: 8080  # 确认端口号
```

**如果8080被占用**:
1. 查找占用进程：
   ```powershell
   Get-NetTCPConnection -LocalPort 8080 | Select-Object OwningProcess
   ```
2. 关闭占用进程，或修改端口号

---

### 5. 编译错误

**检查方法**:
- 查看控制台输出的错误信息
- 检查是否有编译错误

**解决方案**:
- 修复代码错误
- 重新编译项目

---
