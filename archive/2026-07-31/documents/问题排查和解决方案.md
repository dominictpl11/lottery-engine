# 8080端口问题排查和解决方案

## 🚨 问题总结

**现象**: 
- ✅ Java进程已启动（运行约5分钟）
- ❌ 8080端口仍未监听
- ❌ 健康检查接口无法访问

**结论**: 项目启动过程中遇到了问题，未能成功启动到8080端口

---

## 🔍 可能的原因（按优先级排序）

### 1. 数据库连接失败 ⚠️ 最可能

**检查方法**:
```sql
-- 在MySQL客户端执行
SHOW DATABASES LIKE 'lottery_db';
```

**如果数据库不存在**:
```sql
CREATE DATABASE IF NOT EXISTS lottery_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

**检查配置**:
```yaml
# src/main/resources/application.yml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/lottery_db?...
    username: root      # 确认用户名
    password: root      # 确认密码
```

**解决方案**:
1. 确保MySQL服务已启动
2. 创建 `lottery_db` 数据库
3. 执行 `schema.sql` 创建表结构
4. 执行 `test-data.sql` 插入测试数据
5. 检查用户名密码是否正确

---

### 2. Redis连接失败 ⚠️ 很可能

**检查方法**:
```bash
redis-cli ping
# 应该返回: PONG
```

**如果Redis未运行**:
```bash
# Windows
redis-server

# 检查是否运行
redis-cli ping
```

**检查配置**:
```yaml
# src/main/resources/application.yml
spring:
  redis:
    host: localhost
    port: 6379
    password:  # 如果有密码，填写密码
```

**解决方案**:
1. 启动Redis服务
2. 测试连接：`redis-cli ping`
3. 检查配置是否正确

---

### 3. 编译错误

**检查方法**:
- 查看Maven启动的控制台输出
- 查找编译错误信息

**常见错误**:
- 缺少依赖
- 代码语法错误
- 类找不到

**解决方案**:
1. 查看控制台完整错误信息
2. 修复代码错误
3. 重新编译：`mvn clean compile`

---

### 4. 依赖下载失败

**检查方法**:
- 查看Maven下载日志
- 检查网络连接

**解决方案**:
1. 检查网络连接
2. 配置Maven镜像（如果需要）
3. 重新下载依赖

---

## 🛠️ 立即执行的检查步骤

### 步骤1: 检查数据库

```sql
-- 1. 检查数据库是否存在
SHOW DATABASES LIKE 'lottery_db';

-- 2. 如果不存在，创建数据库
CREATE DATABASE IF NOT EXISTS lottery_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 3. 使用数据库
USE lottery_db;

-- 4. 检查表是否存在
SHOW TABLES;

-- 5. 如果表不存在，执行schema.sql
-- 复制 src/main/resources/db/schema.sql 的内容执行

-- 6. 检查是否有测试数据
SELECT COUNT(*) FROM activity;
```

---

### 步骤2: 检查Redis

```bash
# 1. 测试Redis连接
redis-cli ping

# 2. 如果返回 PONG，说明Redis运行正常
# 3. 如果连接失败，启动Redis服务
redis-server
```

---

### 步骤3: 查看启动日志

**重要**: 查看Maven启动的控制台输出，查找：
- ❌ `Could not connect to database` → 数据库连接失败
- ❌ `Unable to connect to Redis` → Redis连接失败
- ❌ `Port 8080 is already in use` → 端口被占用
- ❌ `Compilation failure` → 编译错误
- ✅ `Started LotteryApplication` → 启动成功

---

### 步骤4: 重新启动项目

**如果修复了问题，重新启动**:

```powershell
# 1. 停止当前进程
Get-Process -Name java | Stop-Process -Force

# 2. 等待2秒
Start-Sleep -Seconds 2

# 3. 重新启动
.\mvnw.cmd spring-boot:run
```
