# 数据库初始化指南

## 📋 步骤说明

### 1. 在MySQL客户端执行以下SQL

```sql
-- 创建数据库
CREATE DATABASE IF NOT EXISTS lottery_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 使用数据库
USE lottery_db;
```

### 2. 执行表结构脚本

复制 `src/main/resources/db/schema.sql` 的所有内容到MySQL客户端执行

### 3. 执行测试数据脚本

复制 `src/main/resources/db/test-data.sql` 的所有内容到MySQL客户端执行

### 4. 验证数据

```sql
USE lottery_db;
SELECT COUNT(*) FROM activity;  -- 应该返回 2
SELECT COUNT(*) FROM strategy;  -- 应该返回 2
SELECT COUNT(*) FROM strategy_detail;  -- 应该返回 11
SELECT COUNT(*) FROM award;  -- 应该返回 11
```

## ⚠️ 重要提示

- 数据库用户名：root
- 数据库密码：root
- 如果密码不同，需要修改 `application.yml` 中的配置
