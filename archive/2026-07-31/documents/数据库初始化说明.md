# 数据库初始化说明

## 📋 已创建的文件

1. **init-database.sql** - 完整的数据库初始化SQL脚本
2. **init-database.bat** - Windows批处理脚本（自动执行）

---

## 🚀 初始化方式（选择一种）

### 方式1：使用批处理脚本（推荐，Windows）

1. 双击运行 `init-database.bat`
2. 输入MySQL root用户密码（如果没有密码直接回车）
3. 等待执行完成

### 方式2：使用MySQL命令行

```bash
# 如果有密码
mysql -u root -p [REDACTED_LOCAL_CREDENTIAL] init-database.sql

# 如果没有密码
mysql -u root < init-database.sql
```

### 方式3：在MySQL客户端执行

1. 打开MySQL客户端（命令行或工具如MySQL Workbench、Navicat等）
2. 打开文件 `init-database.sql`
3. 复制所有内容并执行

### 方式4：使用MySQL Workbench

1. 打开MySQL Workbench
2. 连接到MySQL服务器
3. File -> Open SQL Script -> 选择 `init-database.sql`
4. 点击执行按钮（⚡）

## ⚠️ 注意事项

1. **数据库用户权限**：确保使用的MySQL用户有创建数据库和表的权限
2. **数据库已存在**：如果数据库已存在，脚本会使用 `IF NOT EXISTS` 避免错误
3. **数据重复**：使用 `ON DUPLICATE KEY UPDATE` 避免重复插入错误
4. **字符集**：数据库使用 `utf8mb4` 字符集，支持中文和emoji

## 🐛 常见问题

### 问题1：权限不足

**错误**：`Access denied for user`

**解决**：
- 使用root用户执行
- 或给当前用户授予相应权限：
  ```sql
  GRANT ALL PRIVILEGES ON lottery_db.* TO 'your_user'@'localhost';
  FLUSH PRIVILEGES;
  ```

### 问题2：数据库已存在

**现象**：提示数据库已存在

**解决**：这是正常的，脚本会继续执行。如果想重新初始化：
```sql
DROP DATABASE IF EXISTS lottery_db;
-- 然后重新执行脚本
```

### 问题3：表已存在

**现象**：提示表已存在

**解决**：脚本使用 `CREATE TABLE IF NOT EXISTS`，不会报错。如果想重新创建：
```sql
USE lottery_db;
DROP TABLE IF EXISTS award, strategy_detail, strategy, activity;
-- 然后重新执行脚本
```
