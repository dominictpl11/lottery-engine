# 完整启动解决方案

## 🚨 当前问题

项目Java进程已运行，但8080端口仍未监听，说明启动过程中遇到了错误。

## 🔍 必须完成的步骤

### 步骤1: 初始化数据库（必需）

#### 1.1 打开MySQL客户端

#### 1.2 执行以下SQL创建数据库

```sql
CREATE DATABASE IF NOT EXISTS lottery_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE lottery_db;
```

#### 1.3 执行表结构脚本

复制 `src/main/resources/db/schema.sql` 的**所有内容**到MySQL客户端执行

#### 1.4 执行测试数据脚本

复制 `src/main/resources/db/test-data.sql` 的**所有内容**到MySQL客户端执行

#### 1.5 验证数据

```sql
USE lottery_db;
SELECT COUNT(*) FROM activity;  -- 应该返回 2
SELECT COUNT(*) FROM strategy;  -- 应该返回 2
```

---

### 步骤2: 启动Redis服务（必需）

#### Windows:
```bash
redis-server
```

#### 验证Redis运行:
```bash
redis-cli ping
```
应该返回: `PONG`

---

### 步骤3: 检查配置文件

确认 `src/main/resources/application.yml` 中的配置：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/lottery_db?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
    username: root      # 确认你的MySQL用户名
    password: [REDACTED_LOCAL_CREDENTIAL]      # 确认你的MySQL密码
  
  redis:
    host: localhost
    port: 6379
    password:           # 如果有密码，填写密码
```

**重要**: 如果MySQL用户名或密码不是root，请修改配置文件！

---

### 步骤4: 停止并重新启动项目

```powershell
# 1. 停止现有Java进程
Get-Process -Name java | Stop-Process -Force

# 2. 等待2秒
Start-Sleep -Seconds 2

# 3. 重新启动
.\mvnw.cmd spring-boot:run
```

---

### 步骤5: 查看启动日志

**关键**: 查看Maven启动的控制台输出，查找以下错误：

#### 数据库连接错误:
```
Could not connect to database
Communications link failure
Access denied for user
```

**解决方案**:
- 检查MySQL服务是否运行
- 检查数据库是否已创建
- 检查用户名密码是否正确

#### Redis连接错误:
```
Unable to connect to Redis
Connection refused
```

**解决方案**:
- 启动Redis服务
- 检查Redis配置

#### 端口占用错误:
```
Port 8080 is already in use
```

**解决方案**:
- 关闭占用端口的程序
- 或修改端口号

---

## 🔧 如果仍然无法启动

### 方案1: 查看详细错误日志

查看Maven启动的控制台，找到具体的错误信息，然后：
- 如果是数据库错误 → 检查数据库
- 如果是Redis错误 → 检查Redis
- 如果是编译错误 → 修复代码

### 方案2: 简化启动（临时禁用可选功能）

如果RocketMQ和ZooKeeper未运行，可以暂时注释相关配置：

在 `application.yml` 中注释：
```yaml
# RocketMQ配置（暂时注释）
# rocketmq:
#   name-server: localhost:9876

# Dubbo配置（暂时注释）
# dubbo:
#   application:
#     name: lottery-engine
```

**注意**: 这会影响MQ和Dubbo功能，但不影响基本抽奖功能。
