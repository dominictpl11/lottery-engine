## ✅ 解决方案（选择一种）

### 方案1：使用MySQL命令行（推荐）

打开命令行，执行：

```bash
# 如果有密码
mysql -u root -p [REDACTED_LOCAL_CREDENTIAL] init-database.sql

# 系统会提示输入密码，输入后回车即可
```

### 方案2：在MySQL客户端执行

1. **打开MySQL客户端**（MySQL Workbench、Navicat、命令行等）

2. **连接到MySQL服务器**

3. **执行SQL脚本**：
   - 方式A：打开文件 `init-database.sql`，复制所有内容，粘贴到客户端执行
   - 方式B：在MySQL Workbench中：File -> Open SQL Script -> 选择 `init-database.sql` -> 点击执行

### 方案3：使用MySQL Workbench（图形化界面）

1. 打开MySQL Workbench
2. 连接到localhost

5. 查看执行结果

## ✅ 验证初始化结果

执行完成后，在MySQL客户端执行以下SQL验证：

```sql
USE lottery_db;

-- 查看所有表
SHOW TABLES;
-- 应该看到：activity, award, strategy, strategy_detail

-- 查看活动数据
SELECT activity_id, activity_name, stock_count, state FROM activity;
-- 应该返回2条记录：
-- 100001, 春节抽奖活动, 1000, 5
-- 100002, 618抽奖活动, 500, 5

-- 查看数据统计
SELECT 'Activities' as TableName, COUNT(*) as Count FROM activity
UNION ALL
SELECT 'Strategies', COUNT(*) FROM strategy
UNION ALL
SELECT 'Strategy Details', COUNT(*) FROM strategy_detail
UNION ALL
SELECT 'Awards', COUNT(*) FROM award;
```

**期望结果**：
- Activities: 2
- Strategies: 2
- Strategy Details: 11
- Awards: 11

## 💡 提示

- 如果MySQL密码不是root，可以修改 `application.yml` 中的配置
- 如果数据库已存在，脚本不会报错（使用IF NOT EXISTS）
- 如果数据已存在，脚本使用ON DUPLICATE KEY UPDATE避免重复错误
